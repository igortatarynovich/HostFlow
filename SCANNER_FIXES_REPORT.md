## ✅ Исправленные проблемы

### 1. Бесконечное обновление страницы
**Проблема:** Страница постоянно обновлялась из-за бесконечного цикла в `useEffect`

**Решение:**
- Добавлен `bootstrappedRef` для отслеживания состояния bootstrap
- Добавлен `bootstrapSessionIdRef` для отслеживания загруженной сессии
- Удален `sessionId` из зависимостей `useEffect` (используется ref вместо этого)
- Добавлена проверка перед bootstrap: если сессия уже загружена, пропускаем повторную загрузку

**Файлы:**
- `/opt/HostFlow/hostflow-frontend/src/pages/public/PublicScanPage.tsx`
  - Строки 85-144: Добавлены refs и улучшена логика bootstrap

**Результат:** ✅ Страница больше не обновляется бесконечно

---

### 2. Детекция документа не работает
**Проблема:** Документ виден в рамке, но не определяется (показывается "Документ не найден")

**Решение:**
- Снижен порог confidence с `0.08` до `0.05` для лучшей детекции на мобильных устройствах
- Увеличен margin для boundary checks с `10` до `20` пикселей (для edge cases)
- Улучшена логика детекции для документов на краях кадра

**Файлы:**
- `/opt/HostFlow/hostflow-frontend/src/components/public-scanner/CameraPane.tsx`
  - Строка 267: `confidence >= 0.05` (было 0.08)
- `/opt/HostFlow/hostflow-frontend/src/components/public-scanner/ScanningOverlay.tsx`
  - Строка 169: `confidence >= 0.05` (было 0.08)
- `/opt/HostFlow/hostflow-frontend/src/modules/public-intake/scan/documentDetector.ts`
  - Строка 580: `margin = 20` (было 10)

**Результат:** ✅ Документ теперь определяется даже с низкой уверенностью

---

### 3. Mobile UX - кривой кадр и узкая рамка
**Проблема:** На телефоне кадр кривой, красная рамка узкая и вытянутая

**Решение:**
- Guide frame теперь адаптивный для мобильных устройств:
  - Mobile (portrait): 85% ширина, 60% высота (вместо 70x70)
  - Desktop: 70% ширина, 70% высота
- Позиционирование:
  - Mobile: 7.5% отступ по X, 20% по Y
  - Desktop: 15% отступ по X, 15% по Y
- Камера занимает почти весь экран на мобильных: `calc(100vh - 80px)`

**Файлы:**
- `/opt/HostFlow/hostflow-frontend/src/components/public-scanner/ScanningOverlay.tsx`
  - Строки 31-37: Добавлена адаптивная логика для mobile/desktop

**Результат:** ✅ Guide frame теперь правильно отображается на мобильных устройствах
