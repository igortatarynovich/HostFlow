# Исправление видимости оверлея детекции документа

## Проблема
Несмотря на то, что логи показывают, что детекция работает (`[ScanningOverlay] ✅ Creating detectedPath`), визуально оверлей не отображается.

## Внесенные исправления

### 1. Увеличение видимости оверлея
- **Z-index**: Увеличен с `100` до `9999` для контейнера оверлея и SVG
- **Толщина обводки**: Увеличена с `8px` до `20px` для контура обнаруженного документа
- **Размер маркеров углов**: Увеличен с `15px` до `20px` радиус
- **Тени**: Добавлены более сильные тени для лучшей видимости
- **Vector effect**: Добавлен `vectorEffect: 'non-scaling-stroke'` для обеспечения видимости обводок

### 2. Улучшение валидации детекции
- **Покрытие кадра**: Ужесточена проверка - отклоняются квады, заполняющие более 85% кадра (было 98%)
- **Проверка краев**: Добавлена проверка - отклоняются квады, слишком близкие к краям кадра (5% отступ)
- Это должно предотвратить ложные срабатывания, когда весь кадр камеры определяется как документ

### 3. Улучшение индикаторов статуса
- **Z-index**: Увеличен до `10000` для индикатора статуса и подсказок, чтобы они всегда были видны

## Файлы изменены
1. `/opt/HostFlow/hostflow-frontend/src/components/public-scanner/ScanningOverlay.tsx`
   - Увеличен z-index и толщина обводки
   - Улучшена видимость всех элементов оверлея

2. `/opt/HostFlow/hostflow-frontend/src/modules/public-intake/scan/documentDetector.ts`
   - Ужесточена валидация для предотвращения ложных срабатываний

## Что нужно сделать пользователю

### 1. Очистить кеш браузера
После деплоя необходимо очистить кеш браузера:
- **Chrome/Edge**: `Ctrl+Shift+Delete` (Windows) или `Cmd+Shift+Delete` (Mac)
- Выберите "Изображения и файлы в кеше"
- Или используйте режим инкогнито для тестирования

### 2. Проверить консоль браузера
Откройте консоль разработчика (F12) и проверьте:
- Есть ли логи `[ScanningOverlay] ✅ Creating detectedPath`
- Есть ли ошибки JavaScript
- Правильно ли определяются размеры видео (`videoWidth`, `videoHeight`)

### 3. Проверить видимость оверлея
- Оверлей должен быть виден с очень толстой обводкой (20px)
- Угловые маркеры должны быть большими (20px радиус)
- Цвет обводки: зеленый (готово), желтый (почти готово), красный (не найден)

## Ожидаемое поведение

1. **Когда документ не найден**: Красная пунктирная рамка-подсказка
2. **Когда документ найден, но не готов**: Желтая обводка с пунктиром вокруг документа
3. **Когда документ готов к съемке**: Зеленая сплошная обводка вокруг документа

## Если проблема сохраняется

Если после очистки кеша оверлей все еще не виден:
1. Проверьте, что файлы действительно обновились: откройте `/var/www/hostflow-frontend/assets/index-*.js` и проверьте дату изменения
2. Проверьте консоль браузера на наличие ошибок
3. Проверьте, что SVG элемент создается в DOM (в инструментах разработчика)
