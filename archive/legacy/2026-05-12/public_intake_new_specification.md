# Спецификация новой анкеты кандидата (Public Intake)

## Общие требования

- **Мультиязычность**: RU / EN / PL
- **Переключение языка**: в любой момент
- **Автосохранение**: после каждого ответа/действия
- **Навигация**: можно вернуться к предыдущему вопросу
- **После отправки**: просмотр анкеты в режиме только чтения

---

## Структура анкеты

### 🔹 Шаг 0: Выбор языка (только при первом заходе)

**Экран:**
- Выбор языка: RU / EN / PL
- Кнопка "Продолжить"

**Примечание:** Если язык уже выбран (из localStorage/cookie), пропускаем этот шаг.

---

### 🔹 Шаг 1: Минимальные данные

**Поля (все обязательные):**
- Имя (first_name)
- Фамилия (last_name)
- Телефон (phone) с кодом страны (phone_country_code)
- Email (email)

**Пояснение под телефоном:**
> "Мы свяжемся с вами по WhatsApp, чтобы подтвердить данные и отправить инструкцию."

**Кнопка:** "Продолжить"

**Прогресс:**
- Шаг 1 из X — Личные данные ✅ (чекпоинт)

**Валидация:**
- Имя и фамилия: минимум 2 символа
- Телефон: валидный формат с кодом страны
- Email: валидный формат email

---

### 🔹 Шаг 2: Последовательные вопросы (один на экран)

**Формат экрана:**
- Только вопрос (крупным шрифтом)
- Варианты ответа (кнопки или радиокнопки)
- Прогресс: "Вопрос X из Y"
- Чекпоинты по блокам (визуально)
- Никакой лишней информации

**Список вопросов:**

#### Вопрос 1: Где вы сейчас находитесь?
- В Польше
- Не в Польше
- Другое

**Сохраняется в:** `extra.in_poland` (boolean) или `extra.current_location` (string)

#### Вопрос 2: Ваше гражданство?
- Выбор из списка стран (Select с поиском)

**Сохраняется в:** `extra.citizenship` (string - код страны)

#### Вопрос 3: Каким документом подтверждаете пребывание в Польше?
- Виза (visa)
- Карта побыта (karta_pobytu)
- В процессе оформления (in_process)
- Нет документа (none)
- Я гражданин ЕС (eu_citizen)

**Сохраняется в:** `extra.poland_stay_basis` (string)

#### Вопрос 4: Опыт работы водителем CE в ЕС
- 0 лет
- 1-2 года
- 3-5 лет
- 5-10 лет
- 10+ лет
- Или ввод числа в годах

**Сохраняется в:** `extra.experience_ce_total` (number)

#### Вопрос 5: Какие прицепы? (мультиселект)
- Mega
- Standard
- Platform
- Frigo (холодильник)
- Tent
- Container
- Tandem
- Car transporter

**Сохраняется в:** `extra.trailer_types` (string[])

#### Вопрос 6: Есть опыт работы с холодильниками?
- Да
- Нет

**Сохраняется в:** `extra.frigo_experience` (boolean) - **НОВОЕ ПОЛЕ**

#### Вопрос 7: Есть ли международный опыт?
- Да
- Нет

**Сохраняется в:** `extra.intl_experience` (boolean)

#### Вопрос 8: Есть ADR?
- Да
- Нет

**Сохраняется в:** `extra.has_adr` (boolean) - **НОВОЕ ПОЛЕ**

#### Вопрос 9: Дата рождения
- Поле ввода даты (date picker)

**Сохраняется в:** `extra.birth_date` (string 'YYYY-MM-DD')

**Дополнительные вопросы (если есть в карточке, но не в списке выше):**
- Любые другие поля из CandidateExtra, которые можно быстро заполнить

**Навигация:**
- Кнопка "Назад" (кроме первого вопроса)
- Кнопка "Далее" (активна только если ответ выбран)

**Прогресс:**
- Визуальный прогресс-бар с чекпоинтами
- "Вопрос X из Y"
- Зеленый чекпоинт когда блок завершен

---

### 🔹 Шаг 3: Опыт работы (обязательный)

**Экран перед блоком:**
> "Добавьте, пожалуйста, ваши последние места работы (минимум 1). Сейчас мы принимаем только водителей с опытом."

**Форма для одной записи:**
- Должность (position) - text input
- Название фирмы (employer_name) - text input, обязательное
- Страна (country) - select с поиском стран, обязательное
- Дата "От" (start_date) - date picker, обязательное
- Дата "До" (end_date) - date picker, опциональное
- Переключатель "Работаю сейчас" (currently_employed) - checkbox/switch

**Логика:**
- Если "Работаю сейчас" = true → поле "До" скрыто/заблокировано
- Если "Работаю сейчас" = false → поле "До" обязательное

**Добавление:**
- Можно добавить несколько записей (лимита нет)
- Минимум 1 запись обязательна
- Кнопка "Добавить еще одно место работы"

**Попытка пропустить:**
- Если нажать "Пропустить" → модальное окно:
  > "Мы принимаем только водителей с опытом. Необходимо добавить как минимум одного работодателя."
- Кнопка "Понятно" → возврат к форме

**Сохранение:**
- Сохраняется в `employment_history` (CandidateEmploymentEntry[]) или в таблицу `candidate_employments`

**Поля для CandidateEmploymentEntry:**
```typescript
{
  employer_name: string;      // обязательное
  country: string;           // обязательное (код страны)
  position?: string;         // опциональное
  start_date: string;       // обязательное 'YYYY-MM-DD'
  end_date?: string | null; // опциональное 'YYYY-MM-DD' или null если currently_employed
  currently_employed?: boolean; // НОВОЕ ПОЛЕ
}
```

**Прогресс:**
- Чекпоинт "Опыт работы" ✅ когда добавлен минимум 1 работодатель

---

### 🔹 Шаг 4: Документы (пошагово, один документ на экран)

**Экран перед началом блока:**
> "Теперь загрузим документы. Если чего-то нет — вы сможете отметить это. Рекрутер увидит и подскажет, что делать."

**Формат для каждого документа:**
- Название документа (крупным шрифтом)
- Описание/требования (если нужно)
- 3 варианта выбора (обязательно выбрать один):
  1. **Загрузить файл(ы)** → показываем поле загрузки
  2. **"Нет документа"** → блокирует отправку (для обязательных)
  3. **"Документ в процессе оформления"** → можно отправить с пометкой

**Статусы документов:**
- `uploaded` - загружен
- `missing` - нет документа (блокирует отправку для обязательных)
- `in_progress` - в процессе оформления (можно отправить)

---

#### 4.1. Вопрос о правах с кодом 95

**Вопрос:**
> "У вас есть водительские права ЕС с вписанным кодом 95?"

**Если ДА:**
- Загрузка: **Права ЕС (две стороны)** - обязательное
- Можно загрузить 2 файла (лицевая и обратная сторона) или 1 файл с обеими сторонами
- Тип документа: `driver_license_code95`

**Если НЕТ:**
- Загрузка: **Международные права (две стороны)** - обязательное
- Загрузка: **Отдельный документ Code 95** - обязательное
- Типы документов: `driver_license` + `code95` или `qualification_code95`

**Валидация:**
- Если файл не загружен → нельзя продолжить
- Если выбрано "Нет документа" → блокирует отправку
- Если выбрано "В процессе" → можно продолжить

---

**Статусы:**
- Загрузить → обязательное

**Статусы:**

#### 4.7. ADR

**Вопрос:**
> "Есть ADR?"

**Если ДА:**

- Тип документа: `adr` или `adr_certificate`
- Статусы: Загрузить / Нет документа / В процессе

**Если НЕТ:**
- Пропускаем загрузку
- Сохраняем `has_adr: false`

---

**Навигация по документам:**
- Кнопка "Назад" (к предыдущему документу)
- Кнопка "Далее" (активна если выбран статус)
- Для обязательных документов: "Нет документа" блокирует кнопку "Далее"

**Прогресс:**
- Чекпоинт "Документы" ✅ когда все обязательные документы загружены или в процессе

### 🔹 Шаг 5: Финальный обзор перед отправкой

**Страница разделена на блоки:**

#### Блок 1: Личные данные
- Имя, Фамилия
- Телефон, Email
- Дата рождения
- Кнопка "Редактировать" → возврат к Шагу 1

#### Блок 2: Ответы на вопросы
- Все ответы на вопросы из Шага 2
- Кнопка "Редактировать" → возврат к первому вопросу Шага 2

#### Блок 3: Опыт работы
- Список всех работодателей
- Кнопка "Редактировать" → возврат к Шагу 3

#### Блок 4: Документы
- Список всех документов с статусами:
  - ✅ Загружен
  - 🟡 В процессе оформления
  - 🚫 Нет документа
- Кнопка "Редактировать" → возврат к первому документу Шага 4

**Внизу страницы:**
- Чекбоксы согласий:
  - [ ] Согласие на обработку персональных данных (RODO)
  - [ ] Согласие на передачу данных работодателю
  - [ ] Принятие условий использования
  - [ ] Cookies (автоматически если приняты)

**Кнопка:** "Отправить анкету"

**Валидация перед отправкой:**
- Все обязательные поля заполнены
- Все обязательные документы загружены или в процессе
- Все согласия приняты
- Минимум 1 работодатель добавлен

**После отправки:**
- Редактирование заблокировано полностью
- Переход на экран "Спасибо"

### 🔹 Шаг 6: Экран "Спасибо"

**Текст:**
> "Спасибо! Анкета отправлена. Мы проверим ваши данные и свяжемся с вами по WhatsApp. Если возникнут вопросы — напишите вашему менеджеру."

**Кнопка:** "Перейти в обзор"

---

### 🔹 Шаг 7: Обзор (личный кабинет кандидата)

**Большой вертикальный прогресс-бар трудоустройства:**

#### 1. Проверка анкеты и документов
- **Серый** — ждёт проверки
- **Зелёный** — всё подтверждено
- **Красный** — есть замечания

**Если красный:**
- Кандидат может исправить только отклонённые позиции
- Остальные позиции заблокированы для редактирования
- Если рекрутер оставил замечания на другие поля (не документы) → можно редактировать эти поля

**Если документ был загружен рекрутером:**
- Автоматически зелёный статус

---

#### 2. Разрешение на работу — заказано
- **Серый** → не заказано
- **Зелёный** → заказано
- Под статусом → дата заказа

---

#### 3. Разрешение на работу — получено
- **Серый** → не получено
- **Зелёный** → получено
- Под статусом → дата получения

---

#### 4. Подписание договора
- **Серый** → не подписан
- **Зелёный** → подписан
- Под статусом → дата подписания

---

#### 5. «Красная бумага» — заказано
- **Серый** → не заказано
- **Зелёный** → заказано
- Под статусом → дата заказа

---

#### 6. «Красная бумага» — получено
- **Серый** → не получено
- **Зелёный** → получено
- Под статусом → дата получения

---

**Внизу страницы:**
> "Если есть вопросы — напишите вашему менеджеру в WhatsApp"

**Кнопка:** → чат менеджера (WhatsApp link)

**Дополнительно:**
- Просмотр анкеты целиком (режим только чтения)
- Кнопка "Просмотреть анкету"

## Статусы документов

### В анкете (до отправки):
- `uploaded` - загружен
- `missing` - нет документа
- `in_progress` - в процессе оформления

### После отправки (в обзоре):
- `pending` - на проверке (серый)
- `approved` - подтвержден (зеленый)
- `rejected` - отклонен (красный)
