# Исправление видимости оверлея детекции документа

## Проблема
Несмотря на то, что логи показывают, что детекция работает (`[ScanningOverlay] ✅ Creating detectedPath`), визуально оверлей не отображается.

## Внесенные исправления

### 1. Увеличение видимости оверлея
- **Z-index**: Увеличен с `100` до `9999` для контейнера оверлея и SVG
- **Толщина обводки**: Увеличена с `8px` до `20px` для контура обнаруженного документа
- **Размер маркеров углов**: Увеличен до `20px` радиус (было `15px`)
- **Тени**: Добавлены более сильные тени для лучшей видимости
- **Vector effect**: Добавлен `vectorEffect: 'non-scaling-stroke'` для обеспечения видимости обводок

### 2. Улучшение валидации детекции
- **Покрытие кадра**: Отклоняются квады, заполняющие более 85% кадра (было 98%)
- **Проверка краев**: Отклоняются квады слишком близко к краям кадра (5% отступ)
- Это должно предотвратить ложные срабатывания, когда весь кадр определяется как документ

### 3. Улучшение индикаторов статуса
- **Z-index**: Увеличен до `10000` для индикатора статуса и подсказок

## Файлы изменены
1. `hostflow-frontend/src/components/public-scanner/ScanningOverlay.tsx`
2. `hostflow-frontend/src/modules/public-intake/scan/documentDetector.ts`

## Ожидаемое поведение

1. **Документ не найден**: Красная пунктирная рамка-подсказка
2. **Документ найден, но не готов**: Желтая обводка с пунктиром вокруг документа
3. **Документ готов к съемке**: Зеленая сплошная обводка вокруг документа
