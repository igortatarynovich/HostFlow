# 1. RESEARCH SUMMARY (PIPE DRIVE ANALYSIS)

Pipedrive — один из лучших примеров product-led CRM лендинга.

Главная идея их сайта:
не "рассказывать про CRM", а показать **как CRM используется в работе**.

Их лендинг строится вокруг:

1. результат
2. рабочий процесс
3. функции
4. доверие
5. onboarding
6. pricing

Основные элементы:

Hero  
Use cases  
Features  
Automation  
Integrations  
Security  
Onboarding  
Pricing  
FAQ  
Final CTA

Главный принцип:

Product → Workflow → Value

Не:

Features → Features → Features

# 2. КЛЮЧЕВЫЕ ВЫВОДЫ ДЛЯ HOSTFLOW

HostFlow нельзя делать как generic CRM.

Позиционирование должно быть:

Recruitment Operations CRM

Это означает:

Candidate pipeline  
Documents  
Hiring workflow  
Team ownership  

HostFlow должен объяснять продукт через:

Hiring workflow

# 3. ЧТО НЕЛЬЗЯ ДЕЛАТЬ
