

# Scheduler (Планировщик и расписания)

## Цель
Модуль Scheduler обеспечивает планирование и управление событиями, связанными с услугами, документами, встречами, медосмотрами и другими активностями кандидатов и компаний.  
Основная цель — автоматизация записи, напоминаний и синхронизации с внешними календарями.

## Основные функции
- Создание расписаний и слотов для услуг (медосмотр, психотест, обучение).
- Бронирование слотов для кандидатов и компаний.
- Поддержка индивидуальных и групповых записей.
- Синхронизация с календарями Google и Outlook.
- Автоматические напоминания и уведомления.
- Поддержка отмен и переносов.
- Контроль занятости провайдеров и ресурсов (из модуля Providers).
- Отчёты по выполненным и пропущенным событиям.

## Модель данных
- `scheduler_events`: `id, tenant_id, provider_id, service_type, candidate_id, company_id, start_time, end_time, status, notes, created_at, updated_at`
- `scheduler_slots`: `id, provider_id, service_type, start_time, end_time, is_booked, created_at`
- `scheduler_reminders`: `id, event_id, type (email/sms/whatsapp), sent_at, status`
- `scheduler_sync`: `id, calendar_type (google/outlook), access_token, refresh_token, last_sync, tenant_id`

## Логика работы
1. Провайдер или администратор создаёт расписание доступных слотов.
2. Рекрутер или кандидат выбирает подходящее время.
3. При бронировании слот помечается как `booked`, создаётся запись `scheduler_event`.
4. За 24 часа и за 1 час до начала система отправляет напоминания.
5. После завершения события можно отметить статус (`completed`, `no_show`, `cancelled`).
6. Все события синхронизируются с внешними календарями при наличии интеграции.

## API (черновик)
- `POST /scheduler/events` — создать событие.
- `GET /scheduler/events` — получить список событий.
- `GET /scheduler/events/{id}` — детали события.
- `PATCH /scheduler/events/{id}` — изменить статус или время.
- `DELETE /scheduler/events/{id}` — отменить событие.
- `GET /scheduler/slots` — доступные слоты.
- `POST /scheduler/slots` — создать слоты.
- `POST /scheduler/sync/google` — подключить Google Calendar.
- `POST /scheduler/sync/outlook` — подключить Outlook Calendar.

## UI / UX
- Календарный вид (день / неделя / месяц).
- Фильтры по типу услуги, провайдеру, кандидату и компании.
- Интеграция с карточками кандидатов и компаний.
- Цветовая индикация:
  - 🟢 Подтверждено
  - 🟡 В ожидании
  - 🔴 Отменено / Пропущено
- Уведомления о новых записях и изменениях.

## Интеграции
- **Providers:** использование расписаний и доступных слотов.
- **Additional Services:** автоматическое создание событий после заказа услуги.
- **Candidates:** отображение предстоящих событий в портале кандидата.
- **Notifications:** напоминания через email, SMS и WhatsApp.
- **Compliance:** учёт выполненных событий в отчётах.
- **Audit Log:** запись всех действий пользователей.

## Безопасность
- Проверка RLS по `tenant_id`.
- Разграничение прав: кандидаты видят только свои события, агентства — своих клиентов.
- Токены синхронизации календарей хранятся в зашифрованном виде.

## Тест-кейсы
- Создание события → слот помечается как `booked`.
- Отправка напоминаний за 24 и 1 час до события.
- Отмена события → слот снова становится доступным.
- Синхронизация с Google Calendar → событие появляется в календаре.
- Проверка RLS — видимость только в рамках tenant.
