

# Import / Export (Импорт и экспорт данных)

## Цель
Модуль обеспечивает обмен данными между HostFlow и внешними системами (CRM, ATS, ERP, рекламные платформы, таблицы Excel).  
Основная задача — упростить массовую загрузку данных и интеграции с внешними источниками без ручного ввода.

## Основные функции
- Импорт кандидатов, компаний, вакансий, документов, инвойсов.
- Экспорт данных в формате CSV, XLSX, JSON.
- Импорт через UI, API или по расписанию (scheduler job).
- Автоматическое сопоставление колонок при импорте (mapping engine).
- Предпросмотр и валидация перед загрузкой.
- Отчёты об ошибках и дубликатах.
- Поддержка шаблонов импорта для повторного использования.
- Интеграции с рекламными источниками (Meta, TikTok, LinkedIn, Indeed).

## Модель данных
- `import_jobs`: `id, tenant_id, entity_type, file_id, mapping, status, created_by, created_at, completed_at, errors_count`
- `export_jobs`: `id, tenant_id, entity_type, filters, file_id, status, created_by, created_at, completed_at`
- `import_mappings`: `id, tenant_id, entity_type, source_name, mapping_json, created_at`

## Логика работы
1. Пользователь выбирает тип данных (кандидаты, компании и т.д.).
2. Загружает файл или выбирает источник (API, рекламный канал).
3. Система анализирует заголовки и предлагает сопоставление полей.
4. После подтверждения выполняется импорт в фоне (async job).
5. По завершении пользователь получает отчёт с количеством успешно импортированных и ошибочных записей.
6. Экспорт работает аналогично — формируется файл с данными, доступный для скачивания.

## API (черновик)
- `POST /import` — создать импорт.
- `GET /import/{id}` — статус и результаты.
- `GET /import/templates` — список шаблонов.
- `POST /export` — создать экспорт.
- `GET /export/{id}` — статус и ссылка на файл.
- `GET /export/templates` — список доступных типов экспорта.

## UI / UX
- Вкладка **Импорт / Экспорт** доступна пользователям с ролями `OWNER`, `RECRUITER`.
- Интерфейс мастера импорта (шаги: выбор → сопоставление → проверка → запуск).
- Возможность скачать шаблон импорта.
- Индикатор выполнения (progress bar, статус).
- История последних импортов и экспортов.
- Цветовая индикация:
  - 🟢 Успешно
  - 🟠 Частично (ошибки)
  - 🔴 Неудачно

## Интеграции
- **Candidates / Companies / Vacancies:** массовое добавление из файлов и CRM.
- **Documents:** загрузка документов с CSV/ZIP.
- **Invoicing:** экспорт счетов и оплат для бухгалтерии.
- **Scheduler:** автоматический импорт с заданной периодичностью.
- **Webhooks:** уведомление об окончании операций.
- **Audit Log:** фиксация всех импортов и экспортов.

## Безопасность
- Все файлы импортов хранятся в изолированном файловом хранилище.
- Ограничение по размеру: 50 МБ.
- Автоматическая очистка файлов после 30 дней.
- Проверка RLS — операции возможны только в рамках `tenant_id`.

## Тест-кейсы
- Импорт корректного файла CSV → все записи успешно добавлены.
- Ошибка при несоответствии колонок → отчёт с указанием строк.
- Повторный импорт → обновление существующих записей.
- Экспорт списка кандидатов → формируется XLSX, файл доступен для скачивания.
- Проверка RLS — импорт виден только пользователям своего tenant.
