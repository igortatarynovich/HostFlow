

# Tachograph (Тахограф и производственные данные водителей)

## Цель
Модуль Tachograph служит для интеграции с внешними системами контроля и анализа данных с цифровых тахографов, карт водителей и систем телеметрии транспортных компаний.  
Основная задача — объединить HR-информацию кандидатов и сотрудников с эксплуатационными данными для оценки эффективности и соблюдения норм труда.

## Основные функции
- Импорт и хранение данных с карт водителей и тахографов.
- Автоматическая обработка нарушений режимов труда и отдыха.
- Сводка по времени вождения, отдыху, нарушениям.
- Интеграция с системами телеметрии (Transics, Webfleet, Trimble, GBOX, Continental).
- Сопоставление данных тахографа с профилем кандидата.
- Генерация отчётов для HR и флит-менеджеров.
- Уведомления о частых нарушениях и возможных рисках.
- Возможность анализа данных для KPI и бонусных систем.

## Модель данных
- `tachograph_records`: `id, tenant_id, driver_id, source_system, period_start, period_end, driving_hours, rest_hours, violations_count, imported_at`
- `tachograph_violations`: `id, record_id, type, severity, date, description`
- `tachograph_sources`: `id, tenant_id, provider, api_key, last_sync, is_active`
- `tachograph_reports`: `id, tenant_id, driver_id, report_period, total_hours, total_violations, efficiency_score, created_at`

## Логика работы
1. Система подключается к API внешнего провайдера тахографа.
2. Загружаются данные по водителям (driving/rest/violations).
3. Каждому водителю сопоставляется `candidate_id` или `employee_id` в HostFlow.
4. Данные агрегируются и сохраняются в таблицы `tachograph_records` и `tachograph_violations`.
5. Раз в неделю создаются аналитические отчёты с подсчётом показателей.
6. Уведомления отправляются рекрутерам и менеджерам при превышении порогов нарушений.

## API (черновик)
- `POST /tachograph/import` — импорт данных.
- `GET /tachograph/records` — список записей.
- `GET /tachograph/records/{id}` — детали периода.
- `GET /tachograph/violations` — нарушения по водителям.
- `GET /tachograph/reports` — отчёты и метрики.
- `POST /tachograph/sync/{provider}` — синхронизация с провайдером.

## UI / UX
- Вкладка **"Тахограф"** в карточке водителя.
- График активности (дни/часы работы и отдыха).
- Таблица нарушений с фильтрацией по типу и дате.
- Рейтинг эффективности водителя (KPI score).
- Экспорт отчётов в PDF и CSV.
- Цветовая индикация нарушений:
  - 🟢 Без нарушений
  - 🟡 Незначительные
  - 🔴 Серьёзные

## Интеграции
- **Candidates / Employees:** связывает профиль водителя с эксплуатационными данными.
- **Companies:** анализ производственных показателей по клиентам.
- **Reporting:** формирует отчёты и графики по KPI.
- **Compliance:** проверяет соблюдение норм труда и отдыха.
- **Notifications:** уведомления при превышении лимитов.
- **Audit Log:** журнал синхронизаций и импортов.

## Безопасность
- Все данные тахографа анонимизируются и агрегируются.
- Доступ к полным данным только у владельцев tenant и флит-менеджеров.
- Проверка RLS по `tenant_id`.
- Интеграции выполняются через защищённые API-ключи.

## Тест-кейсы
- Импорт данных из внешнего API → создаются записи в `tachograph_records`.
- Нарушения >3 за неделю → уведомление флит-менеджеру.
- Генерация отчёта → корректно рассчитываются KPI.
- Проверка RLS — доступ только для пользователей tenant.
