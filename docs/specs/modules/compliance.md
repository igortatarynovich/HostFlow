

# Compliance & Audits (Соответствие и аудиты)

## Цель
Модуль обеспечивает контроль соответствия документов кандидатов и компаний установленным требованиям, создание журналов комплаенса и экспорт данных для внешних проверок (IRU, ISO, страховщики, клиенты).

## Основные функции
- Формирование снапшотов состояния документов (`documents_compliance_log`).
- Расчёт процента готовности кандидатов и компаний.
- Выявление несоответствий и пропавших документов.
- Экспорт отчётов для аудитов (CSV/PDF).
- Автоматические проверки раз в месяц и при запросе вручную.
- Архивирование устаревших данных по политике retention (24 месяца).
- Возможность сверки с версиями ruleset на дату проверки.

## Модель данных
- `documents_compliance_log`: `id, tenant_id, candidate_id, company_id, ruleset_version_id, compliance_score, missing_types, snapshot_date, created_at`
- `compliance_exports`: `id, tenant_id, export_type, file_id, created_by, created_at`

## Логика работы
1. Планировщик (`compliance_scheduler`) ежедневно проверяет истечение документов и фиксирует состояние.
2. Раз в месяц формируется общий снапшот (`snapshot_date=1-е число месяца`).
3. Пользователь может вручную инициировать проверку через интерфейс.
4. При генерации снапшота фиксируется версия ruleset.
5. Система рассчитывает процент готовности (`ready_docs / required_docs * 100`).
6. Отчёты доступны для скачивания в PDF и CSV, с детализацией по кандидатам и компаниям.

## API (черновик)
- `GET /compliance/logs` — список записей журнала.
- `GET /compliance/logs/{id}` — детали проверки.
- `POST /compliance/trigger` — запуск ручной проверки.
- `GET /compliance/exports` — список экспортов.
- `POST /compliance/export` — создать экспорт CSV/PDF.

## UI / UX
- Раздел **"Комплаенс"** в админке.
- Таблица кандидатов с процентом готовности и отсутствующими документами.
- Возможность выгрузить результат проверки.
- Цветовая индикация:
  - 🟢 100% — Полное соответствие
  - 🟡 70–99% — Частичные несоответствия
  - 🔴 <70% — Критические несоответствия
- Фильтры: по компании, рекрутеру, дате проверки, версии правил.

## Интеграции
- **Documents:** источник данных для расчёта готовности.
- **Ruleset Versioning:** фиксирует правила, актуальные на момент проверки.
- **Reporting & Analytics:** данные комплаенса попадают в сводные отчёты.
- **Audit Log:** запись всех действий проверки и экспорта.
- **Client Portal:** клиенты могут видеть сводку комплаенса своих кандидатов.

## Тест-кейсы
- Автоматическое создание снапшота 1-го числа месяца.
- Ручной запуск проверки через API.
- Выгрузка отчёта в PDF → корректный процент готовности.
- Проверка RLS: каждая запись доступна только в пределах tenant.
- Архивация записей старше 24 месяцев.
