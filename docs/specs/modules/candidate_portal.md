

# Candidate/Employee Portal

## Цель
Дать кандидату/сотруднику личный доступ: видеть прогресс трудоустройства, документы, счета (если услуги платные), контакты менеджеров, уведомления об истечении документов.

## Роли и доступ
- **candidate (owner своего профиля)** — просмотр своего прогресса, загрузка/обновление личных документов, подтверждение согласий.
- **employee** (после трудоустройства) — доступ к справочникам, контактам работодателя/флит-менеджера, графику мед/псих, напоминаниям.
- Доступ через **secure link/token** (временный), 2FA по SMS/Email опционально.

## Функции
- Прогресс по этапам (канон этапов) + чек-лист отсутствующих/истекающих документов.
- Раздел «Документы»: загрузка, просмотр статусов, сроки, комментарии.
- Счета и оплаты (для физлиц): список инвойсов, статус, подтверждение оплаты.
- Контакты: рекрутер, координатор, бухгалтерия, флит-менеджер (после hire).
- Уведомления: expiring soon (30/14/7 дней), новые комментарии, изменения статусов.
- Согласия/RODO: хранение времени и версии текста, отзыв согласий.

## Модель данных (минимум)
- `candidate_portal_access`: `id, candidate_id, token_hash, expires_at, last_seen_at, is_enabled`
- `candidate_consents`: `id, candidate_id, consent_code, text_version, accepted (bool), ip_address, user_agent, payload(json), accepted_at, revoked_at?`
- Использует существующие: `candidate_documents`, `invoices`.

## API (черновик)
- `POST /portal/candidate/session` (email/phone → magic link)
- `GET /portal/candidate/me` (статус, этап, недостающие документы)
- `GET /portal/candidate/documents`
- `POST /portal/candidate/documents` (upload)
- `GET /portal/candidate/invoices`
- `POST /portal/candidate/consents`

## Безопасность
- RLS по `candidate_id`, короткоживущие токены, audit всех действий.
- Маскирование чувствительных полей (паспорт/PESEL → частично).

## Тест-кейсы
- Доступ по просроченному токену — отказ.
- Загрузка документа → статус `uploaded`, событие и уведомление рекрутеру.
- Истечение документа → уведомление + блокировка критичных этапов.
- Просмотр счёта физлица доступен только владельцу.
