

# Reporting & Analytics (Документные отчёты и метрики)

## Цель
Модуль предназначен для сбора, агрегации и визуализации данных по документам, кандидатам и компаниям.  
Основная задача — предоставить управленцам и рекрутерам прозрачную статистику по статусам документов, SLA обработки и динамике соответствия требованиям.

## Основные функции
- Сбор ежедневных метрик по документам и кандидатам.
- Расчёт SLA по проверке документов (upload → approve).
- Подсчёт процента готовности по компаниям и рекрутерам.
- Построение трендов истекающих документов.
- Отчёты по эффективности рекрутеров и компаний.
- Экспорт данных в XLSX и PDF.
- Автоматические еженедельные и месячные отчёты на email.

## Модель данных
- `document_metrics_daily`: `id, tenant_id, date, candidate_id, company_id, total_docs, valid_docs, expired_docs, avg_review_time, reviewer_id`
- `report_summaries`: `id, tenant_id, report_type, period_start, period_end, total_candidates, avg_compliance, avg_sla, created_at`
- `report_exports`: `id, tenant_id, file_id, report_type, created_by, created_at`

## Логика работы
1. Ежедневный процесс (`reporting_job`) собирает метрики из `documents` и `compliance_log`.
2. Рассчитываются:
   - Среднее время проверки документов (SLA).
   - Процент валидных документов на дату.
   - Количество кандидатов с полным пакетом.
3. На основе этих данных формируются агрегаты по дням, неделям и месяцам.
4. Пользователь может вручную запросить отчёт в интерфейсе.
5. Генерация отчёта вызывает экспорт в XLSX или PDF.
6. Отчёты отправляются на email пользователям с ролью `OWNER`.

## API (черновик)
- `GET /reports/documents/daily` — ежедневные метрики.
- `GET /reports/documents/summary` — агрегированные данные по периоду.
- `POST /reports/export` — экспорт отчёта.
- `GET /reports/{id}` — получить файл отчёта.
- `GET /reports/metrics` — доступ к детальным метрикам по рекрутерам.

## UI / UX
- Раздел **"Отчёты"** → вкладка **"Документы"**.
- Фильтры: компания, рекрутер, период, тип документа.
- Диаграммы:
  - Pie Chart — распределение статусов документов.
  - Bar Chart — SLA проверки по рекрутерам.
  - Line Chart — динамика готовности кандидатов.
- Возможность скачивания отчётов (XLSX/PDF).
- Автоматические отчёты по расписанию.

## Интеграции
- **Documents:** источник данных для метрик.
- **Compliance:** расчёт процента готовности.
- **Users:** определение рекрутеров и ролей.
- **Scheduler:** планировщик автоматических отчётов.
- **Audit Log:** фиксация всех экспортов и действий.
- **Email Service:** отправка готовых отчётов.

## Безопасность
- Доступ к отчётам только для пользователей с ролями `OWNER` и `RECRUITER`.
- Все экспортированные файлы доступны только в рамках `tenant_id`.
- Логи экспорта очищаются через 90 дней.
- Защита ссылок токеном при скачивании.

## Тест-кейсы
- Ежедневный сбор метрик → создаются записи в `document_metrics_daily`.
- Ручной экспорт за месяц → формируется PDF-файл.
- Проверка фильтрации по компании → корректное количество кандидатов.
- Автоотчёт на email → отчёт доставлен владельцу tenant.
- Проверка RLS — доступ к отчётам только в рамках tenant.
