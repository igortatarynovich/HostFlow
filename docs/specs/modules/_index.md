

# HostFlow Modules Index

Ниже приведён список всех модулей системы HostFlow, их назначение и текущий статус разработки.

| № | Модуль | Описание | Статус |
|---|---------|-----------|--------|
| 1 | **Auth & RBAC** | Авторизация, роли, RLS, разрешения. | ✅ Core |
| 2 | **User Profile & Preferences** | Личный кабинет, настройки UI, уведомления, сессии. | 🚧 In progress |
| 3 | **Candidates** | Управление кандидатами, этапами, документами. | ✅ Core |
| 4 | **Documents** | Хранение и валидация документов кандидатов. | ✅ Core |
| 5 | **Companies** | Карточки транспортных компаний, реквизиты, контракты. | ✅ Core |
| 6 | **Vacancies** | Управление вакансиями и их требованиями. | ✅ Core |
| 7 | **Contracts & Orders** | Контракты с клиентами, заказы на подбор. | ✅ Core |
| 8 | **Invoicing** | Выставление счетов, учёт оплат. | ✅ Core |
| 9 | **Additional Services** | Платные услуги (медосмотр, Code95 и др.). | ✅ Core |
| 10 | **Client Portal** | Портал клиента для просмотра кандидатов и счетов. | ✅ Core |
| 11 | **Candidate Portal** | Портал кандидата с документами и статусами. | ✅ Core |
| 12 | **Document Templates** | Шаблоны документов, рендеринг PDF/HTML. | ✅ Core |
| 13 | **Company Profile** | Расширенный профиль компании (флот, контакты, контракты). | ✅ Core |
| 14 | **Ruleset Engine** | Правила зависимостей документов и стадий. | ✅ Core |
| 15 | **Compliance & Audits** | Снапшоты состояния документов, экспорт для проверок. | 🧩 Planned |
| 16 | **Reporting & Analytics** | Метрики, SLA и статистика документов. | 🧩 Planned |
| 17 | **Bulk Operations** | Массовые действия для рекрутеров. | 🧩 Planned |
| 18 | **Ruleset Versioning** | Версионирование правил и их аудит. | 🧩 Planned |
| 19 | **Providers Network** | База медицинских/обучающих провайдеров. | 🚧 In progress |
| 20 | **Scheduler** | Расписание услуг, интеграции с календарями. | 🚧 In progress |
| 21 | **Payments** | Онлайн-оплаты (Stripe/Revolut/Przelewy24). | 🚧 In progress |
| 22 | **E-signature** | Электронные подписи (Autenti/DocuSign). | 🚧 In progress |
| 23 | **Approvals** | Согласования контрактов и документов. | 🚧 In progress |
| 24 | **Fin Checks** | Проверка NIP/VIES/KSeF перед инвойсами. | 🧩 Planned |
| 25 | **Identity Verification** | OCR, selfie, верификация личности. | 🧩 Planned |
| 26 | **Logistics** | Билеты, трансфер, проживание кандидатов. | 🧩 Planned |
| 27 | **Onboarding** | Передача кандидата клиенту, чек-лист. | 🧩 Planned |
| 28 | **Training** | Обучение, Code95, ADR refresh. | 🧩 Planned |
| 29 | **Import/Export** | Импорт/экспорт данных и интеграции. | 🧩 Planned |
| 30 | **Webhooks & API Keys** | Вебхуки, уведомления и интеграции. | 🧩 Planned |
| 31 | **Tachograph** | Интеграция с тахографами, контроль нарушений. | 🧭 Roadmap |
| 32 | **Matching Engine** | Подбор кандидатов по флоту и маршрутам. | 🧭 Roadmap |

### Легенда
- ✅ Core — реализовано и активно используется.
- 🚧 In progress — в разработке.
- 🧩 Planned — утверждено в планах ближайших спринтов.
- 🧭 Roadmap — долгосрочные идеи/исследования.
