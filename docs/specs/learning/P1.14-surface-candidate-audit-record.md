# P1.14 — Surface Candidate Audit Record

**Status:** Implemented (`day_surface_candidate_audit_v1`).

Fix the P1.13 selected surface candidate as a verifiable audit artifact so later phases can link selection, exposure, reaction, and learning without mutating memory or UI.

## Scope

| In scope | Out of scope |
|----------|----------------|
| Builder + validator for `day_surface_candidate_audit_v1` | UI rendering |
| Default exposure/reaction/learning statuses | HTTP API |
| Trace refs (render / LLM) | Learning signal writes |
| Stable output shape + tests | Dataset approval |
| | User profile storage |

## Record: `day_surface_candidate_audit_v1`

| Field | Meaning |
|-------|---------|
| `audit_id` | Stable record id |
| `surface` | Target surface id |
| `candidate_id` | Selected candidate UUID |
| `selected_source` | `deterministic` / `llm_refined` / `blocked` |
| `display_text_hash` | SHA-256 of normalized display text; `null` when blocked |
| `display_text_snapshot` | Optional trace snapshot; omitted when blocked |
| `selection_reason` | Reason code/string from P1.13 |
| `used_llm` | Derived from `selected_source` |
| `dataset_candidate` | Whether candidate is eligible for dataset capture |
| `quality_score` | From selected candidate |
| `confidence` | Inherited confidence |
| `degraded` | Degraded-path flag |
| `render_trace` | `package_ref`, `evaluation_ref`, `render_ref` |
| `llm_trace` | `generation_ref`, `prompt_ref`, `response_ref` |
| `created_at` | UTC timestamp |
| `ui_exposure_status` | Default `not_exposed` |
| `reaction_status` | Default `pending` |
| `learning_status` | Default `not_processed` |

## Invariants

- Every selected candidate produces an audit record via `build_day_surface_candidate_audit_v1`.
- `deterministic` ⇒ `used_llm=false`; `llm_refined` ⇒ `used_llm=true`.
- `blocked` ⇒ `display_text_hash=null` (snapshot also omitted).
- Audit record does **not** imply the text was shown to the user.
- Raw user profile keys (`email`, `phone`, `personal_data`, …) must not appear in the record.
