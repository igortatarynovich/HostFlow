# Wireframe: «Создать подбор» — M1 Money Path

**Status:** **implemented** (M1 money path PR — wizard + ready + search home).  
**Parent:** [`m1-money-path.md`](m1-money-path.md)  
**Scope:** 3 шага + «Подбор готов» + Home одного подбора.  
**Код:** первый PR **после** prototype validation ([§ Gate](#gate-перед-первым-pr)).

---

## Гипотеза

Главный вопрос пользователя после 3 шагов — не «Где моя ссылка?», а:

> **«Что мне делать дальше?»**

Экран «Подбор готов» отвечает на него пошагово. Если пользователь всё равно спрашивает «А что теперь делать?» — **код писать рано**.

---

## Вход в flow

| Откуда | Действие |
|--------|----------|
| **Launchpad** | Primary CTA: **«Создать подбор»** |
| Recruitment (0 подборов) | Тот же CTA |
| Setup Hub | **Не** вход happy path |

---

## Flow (3 шага)

```text
  1. Кого ищем?  →  2. Для кого?  →  3. Подбор готов  →  Home подбора
```

**Целевое время:** ≤ 3 мин после Launchpad.

---

## За кадром (пользователь не видит)

После шага 2 HostFlow автоматически: подбор (Vacancy), название, стандартная анкета, ссылка, QR, владелец = текущий user, дефолтная воронка + профиль по роли.

## Экран 3 — «Подбор готов» ★

**Шаг 3/3** — **V1 PASS** после этой версии.

Фокус: **следующие шаги**, не технические блоки «ссылка / QR». URL **не** показываем крупно — только действие «Копировать».

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  Подбор готов                                                │
│                                                              │
│  Теперь вы можете начать получать кандидатов.                │
│                                                              │
│  ── Шаг 1 ──                                                 │
│  Скопируйте ссылку                                           │
│                                                              │
│  [  Копировать  ]                                            │
│                                                              │
│  или скачайте QR                                              │
│  [  Скачать  ]                                               │
│                                                              │
│  ── Шаг 2 (необязательно) ──                                 │
│  Подключите Meta Ads                                         │
│                                                              │
│  [  Подключить  ]                                            │
│                                                              │
│  или  Сделаю позже                                           │
│                                                              │
│  ─────────────────────────────────────────────────────────   │
│  Когда люди начнут заполнять анкету,                         │
│  все отклики автоматически появятся здесь.                   │
│                                                              │
│  [  Открыть подбор  ]                                        │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

| Элемент | Поведение |
|---------|-----------|
| **Копировать** | В буфер + toast «Ссылка скопирована» |
| **Скачать** | QR PNG |
| **Подключить** | Meta flow (не блокирует; можно пропустить) |
| **Сделаю позже** | Text link / secondary — dismiss шага 2 |
| **Открыть подбор** | Secondary на success; primary action уже «Копировать» |
| Raw URL | Скрыт или под «⋯» — не hero |

**Anti-patterns:** «Ваш подбор создан» без инструкции; видимый URL как главный элемент; Settings; gates.

### После первого отклика

```
│  ── Есть новые отклики ──                                    │
│  Jan Kowalski · 2 мин назад                    [ Открыть ]  │
│                                                              │
│  ── Последние отклики ──                                     │
│  Jan Kowalski · 2 мин назад                                  │
```

| Было (v1) | Стало |
|-----------|-------|
| «0 откликов / 0 кандидатов» | «Пока нет откликов» + мотивация |
| Блок «Сегодня» со статистикой | Состояние работы |
| CRM-пустота | «Как только появится первый отклик…» |

**Не добавлять:** «+ Создать ещё подбор» на первом экране Home — отвлекает от гипотезы (можно в Launchpad).

## Gate перед первым PR

Показать прототип (Figma / HTML / staging mock) **1–2 не-разработчикам**. Facilitator молчит после экрана «Подбор готов».

### Главный критерий (обязательный)

| Реакция | Вердикт |
|---------|---------|
| *«Теперь мне нужно пойти в Meta и вставить эту ссылку.»* (или WhatsApp / сайт) | **GO** → первый PR |
| *«А что теперь делать?»* | **NO-GO** → только доработка экрана «Подбор готов» |

### Checklist

| # | Вопрос | Review |
|---|--------|--------|
| **V0** | Meta / «что делать дальше» (таблица выше) | ☐ GO / NO-GO |
| V1 | «Подбор готов» — работа закончена, шаги понятны | ☑ PASS |
| V2 | Шаг 2 — клиент одной строкой | ☑ PASS |
| V3 | Home — место одного подбора, не CRM | ☑ PASS |
| V4 | Пустой Home мотивирует, не пугает нулями | ☐ |
| V5 | ≤ 3 мин до «Копировать» | ☐ |
| V6 | Нигде Settings / gates | ☐ |

**V0 GO + V4–V6** → реализация.

---

## PR scope (когда V0 GO)

1. Wizard: экраны 1–2 + loading «Готовим…»  
2. Success: «Подбор готов» (layout выше)  
3. Search Home: один подбор, состояние откликов  
4. Backend glue: vacancy + lead form + link + QR (существующие API)  
5. E2E: signup → копировать → public submit → отклик на Home  

**Не в PR:** ADR, Entity Spec, рефактор nav, Meta OAuth (кроме кнопки-заглушки → settings).
