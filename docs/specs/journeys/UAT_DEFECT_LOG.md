Журнал дефектов для прогонов **2.2.C–2.2.J** по чеклистам в этом каталоге. Баги **не** правятся в journey-файлах: сюда — запись, в **`docs/SSOT.md` §2.1** (или issue-трекер команды) — owner, severity, ETA.

## Как пользоваться

1. Перед сессией: в строке таблицы ниже указать **дату**, **персону** (файл), **тенант/план**, **исполнителя** (QA).
2. Во время сессии: для каждого дефекта — новая строка: краткое описание, severity (**P0** блокер / **P1** / **P2**), шаг чеклиста (опционально).
3. После: проставить **статус** (`open` / `fixed` / `wontfix` / `duplicate`) и ссылку на PR/issue при наличии.
