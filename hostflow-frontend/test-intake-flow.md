## Проверка валидации данных:

### Поля, которые должны быть валидными:
1. `citizenship`: null или строка длиной ровно 2 символа (например, "PL", "UA")
2. `country` в employment: null или строка длиной ровно 2 символа
3. `employer_name`: не может быть пустым
4. `birth_date`: null или строка формата "YYYY-MM-DD"
5. `years_ce`: null или число (не строка!)
6. `frigo_experience`: null, true или false (не строка "yes"/"no"!)
7. `has_adr`: null, true или false (не строка "yes"/"no"!)
8. `intl_experience`: null, true или false (не строка!)

### Поля, которые не должны вызывать 422:
- Все строковые поля должны быть либо null, либо непустыми строками
- Все числовые поля должны быть числами или null
- Все булевы поля должны быть boolean или null
