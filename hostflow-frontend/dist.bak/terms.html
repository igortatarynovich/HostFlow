1. Purpose of the Application

HostFlow Leads is a web service connecting Meta (Facebook, Instagram) lead forms with the HostFlow recruitment platform via a secure webhook. The purpose of the application is to automatically receive and process contact data voluntarily submitted by users through Meta lead forms. The application does not provide user registration, login, or interaction within the Facebook environment.

2. Data Collection and Use

The application only collects data explicitly submitted via Meta lead forms (e.g., name, phone number, email, and message content). These data are securely transmitted to the HostFlow system (https://hostflow.cc) and used solely for contact and recruitment purposes. Data are not shared or sold to third parties, except when required by law.
