# Candidate Portal - План улучшений

## Текущее состояние

### ✅ Реализовано:
1. **PublicApplyPage** - основная страница подачи заявки
2. **PublicStatusPage** - страница просмотра статуса
3. **PublicTimeline** - компонент таймлайна
4. **PublicScanPage** - сканирование документов через камеру
5. **Magic links** - доступ по email/phone
6. **Share tokens** - публичные ссылки на статусы
7. **Загрузка документов** - через форму и сканер

### ❌ Что нужно улучшить:

1. **Автообновление статусов в реальном времени**
   - Текущее: только ручной refresh
   - Нужно: автоматический polling каждые 30-60 секунд
   - Показывать индикатор "обновляется..."

2. **Система уведомлений для кандидатов**
   - Push-уведомления (через браузер)
   - Email-уведомления при изменении статуса
   - SMS-напоминания (опционально)

3. **Улучшенный таймлайн**
   - Визуализация прогресса (progress bar)
   - Детали по каждому этапу
   - Оценка времени до завершения

4. **Улучшенный share-link**
   - QR-код для быстрого доступа
   - Настройка срока действия
   - Статистика просмотров

5. **Мобильный опыт**
   - PWA (Progressive Web App)
   - Офлайн-режим для просмотра статусов
   - Улучшенная камера для сканирования
